# Quran Quest — The Emerald Vale
A 3D browser game for memorizing Al-Fatiha and all of Juz ʿAmma (surahs 78–114). Walk a green valley, enter the **Portal of Surahs** to choose a surah, and its shrines rise along a spiral path. At each shrine, read the ayah, then rebuild it from shuffled tiles and fill in the missing word.

- Per-surah timer, best times, and time estimates (based on your own pace)
- XP and levels, quest log, mini-map, compass arrow; progress saved in localStorage
- Keyboard and mouse (WASD, drag, E, M) or touch (joystick, drag, ✦)

Arabic: Uthmani (Tanzil, via api.alquran.cloud); English: Sahih International. Built with Three.js.

**Play:** https://mrbugimposter3-ship-it.github.io/quran-quest/
